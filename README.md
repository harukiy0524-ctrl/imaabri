# めぐる今治 物語完全版 Ver.1.0

場所ごとのストーリーを中心にした、公開可能な観光Webアプリです。

## 収録内容
- 24の場所・体験ストーリー
- 朝・昼・夕方・雨の日の4種類の語り
- 6章のストーリーコース
- 次の場所へつながる物語導線
- OpenStreetMap地図・現在地表示
- 読了記録・訪問記録・旅のメモ
- 相棒「みなと」の案内
- スマートフォン対応・PWA基本対応
- 公式情報への導線

## 起動
基本画面は `index.html` を開くと確認できます。
地図、現在地、PWAはHTTPSまたはローカルサーバーで利用してください。

```bash
cd meguru-imabari-story-complete
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 無料公開
フォルダ内のファイルをCloudflare Pages、GitHub Pages、Netlify等へアップロードします。ビルドは不要です。

## 公開前の確認
- 座標、施設名称、公式リンク
- 営業時間・休業・料金・運航情報
- 利用規約、プライバシーポリシー、運営者表示
- 施設・自治体による文章監修
- 写真を追加する場合の使用許諾

物語部分は観光体験を豊かにするための独自文章です。基礎情報は今治市・今治地方観光協会等の公開情報を参考にしています。
